# 2026-05-04 — Manga Maker 3D Rendering Fix

## Problem
Page was not showing centered in the game window. Camera at (450,800,500), page appeared offset.

## Root Cause
When Page is added with `page.global_position = (450, 800, 0)`, children at LOCAL position (450, 800, 400) inherit the parent's world position AND add their own. So child ends up at world (900, 1600, 400) — outside camera view.

This is basic Node3D transform inheritance: parent position DOES affect children world positions.

## Solution
- ViewportMesh/MeshInstance3D inside Page should use LOCAL position `(0, 0, z)` — within the Page node's local space
- Page's Page node itself is at world (450, 800, 0) — center of 900x1600 page
- Child objects at local (0,0,z) get world (450,800,z) — correct camera alignment

## Final Working Sprite3D Setup (page.gd)
- viewport_sprite.texture = tex (ViewportTexture from SubViewport)
- viewport_sprite.region_enabled = true
- viewport_sprite.region_rect = Rect2(0, 0, 900, 1600)
- viewport_sprite.position = Vector3(0, 0, 200)  # LOCAL to Page
- viewport_sprite.billboard = BaseMaterial3D.BILLBOARD_ENABLED
- viewport_sprite.flip_v = true
- viewport_sprite.pixel_size = 1.0
- Page node's global_position must be set BEFORE add_child in main.gd
